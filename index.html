Instructions disponibles

            

              
LDA addr
ACC ← mem16[addr]Code op : 0000

              
STO addr
mem16[addr] ← ACCCode op : 0001

              
ADD addr
ACC ← ACC + mem16[addr]Code op : 0010

              
SUB addr
ACC ← ACC - mem16[addr]Code op : 0011

              
JMP addr
Effectue un saut à l’adresse indiquée.Code op : 0100

              
JGE addr
Effectue un saut si la valeur de l’accumulateur est positive ou nulle.Code op : 0101

              
JNE addr
Effectue un saut si la valeur de l’accumulateur est non nulle.Code op : 0110

              
STP
Arrête le microprocesseur.Code op : 0111

              
AND addr
ACC ← ACC and mem16[addr]Code op : 1000

              
OR addr
ACC ← ACC or mem16[addr]Code op : 1001

              
XOR addr
ACC ← ACC xor mem16[addr]Code op : 1010

              
ROL addr
ACC ← ACC rol mem16[addr] Rotation à gaucheCode op : 1011

              
LDR addr
R ← addrCode op : 1100

              
LDI
ACC ← mem16[R] ; R ← R + 1Code op : 1101

              
STI
R ← R - 1 ; mem16[R] ← ACCCode op : 1110

              
XPC
ACC ↔ PC
Échange entre ACC et PC.Code op : 1111

            

            

              
            

            

              
Directives du préprocesseur

              

                
.org
Désigne l’adresse mémoire où se trouvent les instructions ou données placées juste après.

                
defw
Déclare une donnée de type word (16 bits) à l’adresse du label, avec une valeur initiale en décimal ou en hexadécimal.x        defw 10
y        defw 0xf

                
; commentaire
Introduit un commentaire jusqu’à la fin de la ligne. Il n’a aucune action.

                
Label
Un label est un mot-clé (de 8 caractères) désignant plus simplement une adresse mémoire. loop et x sont des labels dans l’exemple ci-dessous.loop  LDA  x
